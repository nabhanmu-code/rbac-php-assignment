# RBAC Program in PHP

This is a small Role-Based Access Control (RBAC) program written in PHP.
It was made for the Software Security course (SDEV 4303), Chapter 04: Access Control.

## Roles and permissions (Account object)
- Admin: Create, View, Update, Delete
- Manager: View, Update
- Customer: View

## How to run
1. Install XAMPP and start Apache.
2. Copy rbac.php to C:\xampp\htdocs\rbac\
3. Open http://localhost/rbac/rbac.php in the browser.
